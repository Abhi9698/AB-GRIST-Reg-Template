Setup guide

  1. Add a Custom widget to a page and link it to the Samples table.
  2. Use this widget's hosted URL.
  3. Set access to Full document access.
  4. Pick or type a Box ID, click a slot, then Register sample.

Outside Grist the widget runs in demo mode with local sample data.
